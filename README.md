# sasaru

手元のショート動画の型を読む、Cursor と Claude Code 用のスキルプラグイン。

ショート動画を一本渡すと型を読んで playbook として残し、型を選んで自分のコンテンツで作る。ルーターと原則のスキル、playbook のスキーマ（`schema/playbook.schema.json`）とテンプレート（`templates/playbook.md`）がある。取り込み、選択、制作、ゲートの各スキルの本文と、取り込みのスクリプトはまだ無い。インストールできるリリースも無い。

ライセンスは MIT。条文は `LICENSE`。

貢献と機能要望はまだ受けない。

置かないもの:

- 鍵
- 本人の顔写真
- 声の ID と参照音声
- 他人のリールファイル
- 再配布の許諾が無い BGM

株式会社ササル、CeVIO の「ささら」、Cursor、GitHub の公式製品ではない。
