# Captions Read as Headlines

playbook には参照で測った大きさをそのまま書く。作るときに、`captions.role` が `headline` で、測った `capHeightRatio` が 0.04 未満なら、見出しの帯へ上げる。上げたことと、上げた値を制作記録に書く。

手元の基準は、白い芯の高さが画面高の 0.056〜0.059（地の句）、0.071〜0.080（強調）、縁は黒 8〜10 px（1080 幅）。細い白字の中央一行（約 0.02）はチープに見えて不合格になった。

位置は参照ごとに測る。縦の位置を定数にしない。
