# Captions Read as Headlines

この原則は、一本の参照の数を定数にしない **sasaru-principle-measure-or-label** の例外である。基準はユーザーの判定と、その判定のあとに作り直した一本の実測から来ている。

playbook には参照で測った大きさをそのまま書く。作るときに、`role: headline` の層の `capHeightRatio` が 0.04 未満なら、見出しの帯へ上げる。上げたことと、上げた値を制作記録に書く。

基準の帯。白い芯の高さは画面高の 0.056〜0.059（地の句）、0.071〜0.080（強調）。縁は黒 8〜10 px（1080 幅）。細い白字の中央一行（約 0.02）はチープに見えて不合格になった。

位置は参照ごとに測る。縦の位置を定数にしない。
